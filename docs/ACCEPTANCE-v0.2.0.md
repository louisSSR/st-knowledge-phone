# v0.2.0 实现与验收

2026-09-20，运行代码提交 `8566c955e2d2efc5e379afdaa084a7825732fbbe`。测试通过不等于用户已做最终体验验收；未设置 `driver-accepted`。

## 完成的转向

正式资料从自编规则和逐篇摘录，改为现成 ZIM 库的索引和原文。旧十个项目资料包从正式搜索、推荐、目录及收藏展示撤出，物理文件与用户已有记录不擅自删除。JSON 仅保留高级自定义入口。

当前一次连接一个本地文件，按需读取，不全库复制到 IndexedDB；刷新后明确要求重新选择同一文件。库 UUID 维持收藏身份。使用标题索引与全文索引，标题精确优先；中文全文候选核对连续词语，过滤散字误命中。每次最多核对 30 个全文候选、展示 100 个合并结果，不把有界检索说成全部结果。

主页从聊天明确标注的话题生成点击检索入口；推荐理由来自标题、命中片段和原文链接，不生成百科说明。

## 未验与边界

- 中文 Wikipedia 14.75 GB 整库没有下载或性能验收；现成架构支持按需读取并不等于该规模已通过。
- 390px 是浏览器模拟，不是手机真机；Firefox、低端设备和大库内存仍待实际测试。
- 无图归档本来缺图；SVG、视频、动态脚本互动和无 MathML 的动态公式不承诺呈现。静态 MathML 已实测。
- 归档月份来自文件名提示，并以月末保守过滤；不能作为逐条历史可知时间证据。简繁体和同义词未做全量转换。
- 单库连接、刷新后重新选择、有限候选核验、同源多账户存储未隔离等边界保持公开；资料事实本身不因索引成功而自动正确。
