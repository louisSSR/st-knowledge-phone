用户原浏览器保留着旧 ZIM 连接记录，因此补测发现：联网模式的知库页面仍会显示重选文件提示。最终代码仅在离线模式显示该提示，新增自动回归通过；在原酒馆浏览器刷新复查，提示为空、1 篇已读缓存保留并可直接打开。此场景由用户原浏览器验证，不用全新测试 profile 代替升级证据。

真实酒馆抽查「斗地主」「光合作用」「相对论」，来源精确条目均列首位；斗地主由来源重定向到「鬥地主」。正文保留农民、底牌、叫牌等术语、表格与规则段落，点击「撲克牌」可继续打开原文。来源链接实际打开对应 `oldid` 版本网页。表格、静态 MathML 和页面原文保留，不用片段拼装答案。

本次真实酒馆查询耗时分别约 3.15、1.02、1.06 秒，仅为该轮网络测量，不是延迟承诺。已读缓存断网打开没有 HTTP 请求；联网查询在断网时明确失败，匹配缓存以「已读缓存／不是实时结果」展示。默认初次打开手机不发查询，不上传聊天正文、身份、日期或地点。

真实宿主仍有加载阶段既存的 `SyntaxError: Unexpected token '}'`，单独作为基线记录；本轮新增页面错误为 0。独立预览页面错误为 0。没有将宿主其他扩展的潜在请求算成知库请求，也不宣称整个宿主永远零网络。

## ZIM 修复的证据边界

原实现有可验证的问题：超时后关闭引擎并丢失后续可读连接，标题结果也会等待全文检索。新版按初始化、标题、全文、正文读取报告阶段；保留当前页面的 File，初次连接超时提供直接重试，后续请求可恢复同一文件；标题命中不再等待全文。

测试文件为官方中文维基教科书 `wikibooks_zh_all_nopic_2026-07.zim`，98,984,637 字节、8,302 篇。故障注入主动丢弃一次初始化响应、一次全文响应，并仅在测试中将超时缩短到 2.5 秒；最终仅选择一次文件，原文与术语表恢复可读。这证明恢复路径有效，**不证明已经定位用户先前那次自然超时的具体触发原因**。

## 尚未覆盖

- 当前只有中文维基百科一个在线来源，不是全网搜索，不保证全部名词覆盖或来源事实全部正确。
- 在线资料及其缓存是现代参考，未核验剧情历史版本；ZIM 的文件名月份也不能替代逐条历史核验。
- 缓存限 20 页／10 MiB，保存已读正文；图片、音视频、外部样式和互动组件不自动下载。未缓存内容不能离线取得，收藏不固定缓存。
- 未实测 14 GB 中文维基百科 ZIM、手机真机、低端设备及所有页面结构。
- 本机网络成功不保证任何地区或后续时刻能访问官方来源；失败时明确提示，不偷偷改用镜像。

本地证据位于被 Git 忽略的 `evidence/online/preview-acceptance.json`、`host-acceptance.json`、对应截图、`evidence/zim/timeout-acceptance.json` 和 `online-unit-tests.log`。包含私有宿主信息的完整服务日志不发布。用户实际试用仍是下一道验收，不由自动脚本代签。
