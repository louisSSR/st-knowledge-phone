# 掌上知库 · Knowledge Phone

SillyTavern 浏览器扩展。默认联网检索成熟来源，点击结果阅读来源正文，沿原文链接理解名词；读过的页面缓存在本地。当前接入中文维基百科，ZIM 是可选离线来源。扩展不调用模型写百科，也不将搜索片段拼装成全文。

## 安装与开始使用

1. SillyTavern ≥ 1.18.0 → 扩展 → 安装扩展：https://github.com/louisSSR/st-knowledge-phone
2. 打开右下角「掌上知库」，输入名词并搜索，无需先下载资料包。
3. 打开结果阅读来源正文，点击正文中的中文维基百科词条链接继续查词；可按当前聊天收藏。
4. 已读页面可在「知库」的本地缓存中打开。需要完全离线资料库时，再选择 ZIM。

无需 API Key、模型费用或额外后台服务。联网搜索直接访问 zh.wikipedia.org 官方接口；仅发送你提交的查询词、打开的词条标题和接口参数，不上传聊天正文、聊天身份、历史记录、剧情日期或地点。启动扩展、接收聊天消息和提取关键词不会自动发起联网查询。点击一个关键词作为查询入口时，会发送该查询词。

## 搜索、原文与缓存

- 当前在线来源是中文维基百科，每次最多展示 12 条结果；标题和来源重定向精确匹配优先。片段来自来源检索接口，不是插件生成的解释。单一来源不保证覆盖所有主题或名词。
- 阅读使用来源返回的正文 HTML，保留章节、列表、表格、静态 MathML 公式和可用词条链接。署名、原始地址、修订链接与资料许可属于来源，不标为插件原创。
- 阅读器停用脚本、表单、视频和互动组件。在线图片及外部样式不自动下载；需要图片或原站功能时，点击来源链接在外部网页阅读。不能将此阅读视图视为原网站的完整副本。
- 仅成功读取的正文进入缓存，最多 20 页、总计 10 MiB；超限按成功获取顺序淘汰最旧页面。缓存不预抓取未读链接，也不下载整个百科。页面过大或浏览器保存失败会明确提示。
- 缓存在同一浏览器的扩展数据库中共享；历史记录和收藏按聊天保存。收藏不会锁定缓存，旧缓存被淘汰后需要重新联网读取。
- 联网失败时明确提示；存在匹配缓存才显示「已读原文缓存」，不会将其标为实时结果。直接打开缓存不需要联网。网络或地区限制可能导致官方站点不可达，扩展不会暗中切换镜像或代理。

默认联网查阅是现代科普资料，**未按剧情年代核验**。获取时间、来源更新时间和历史可知时间是不同概念；修订号也不代表整篇资料在过去某个日期已经可知。离线剧情模式继续使用已有日期与地点过滤，联网科普不会改写该聊天的剧情设置。

## 可选的 ZIM 离线库

在「知库」连接完整 .zim 文件，并切换到离线检索。下载后直接按需读取原文件，不重新采集、切片或复制整库到浏览器数据库；当前一次连接一个库。刷新页面后需重新选择同一文件，无需重新下载。

- [Kiwix 官方库目录](https://library.kiwix.org/)：按语言、主题和体积选择资料。
- [中文维基教科书，2026-07，无图，94.40 MiB](https://download.kiwix.org/zim/wikibooks/wikibooks_zh_all_nopic_2026-07.zim)：历史验收样本，8,302 篇；包含「扑克」和「扑克/术语表」，并非通用百科覆盖证明。不是默认下载项。
- [维基百科整库目录](https://download.kiwix.org/zim/wikipedia/)：nopic 保留正文、无图；mini 只有导言。中文 nopic 2026-07 约 14.75 GB，本项目未实测该整库或手机真机。

ZIM 搜索先返回标题匹配；没有标题匹配时才检索正文，最多核对 30 个全文候选，不声称穷尽整库。查询超时会区分打开、标题、全文或读取阶段；当前页面保留已选文件，初次连接超时可直接重试，检索超时后的下一次操作会尝试恢复连接。这些恢复措施不等于已定位用户先前自然发生的超时根因。

ZIM 快照日期目前来自文件名月份，并以月末保守过滤，**不是逐条历史版本核验**。2026 年快照不能用于 2008 年的严格剧情；没有日期的库也不可用于严格时间线。日常离线科普可选择现代模式或明确关闭严格时间线。随附的 OpenZIM 引擎约 2.32 MB，知识库文件另行选择。

## 旧版迁移

v0.1 的原创演示与 105 篇 Wikipedia 摘录已退出正式搜索、推荐与目录；它们只保留作开发测试资产。更新不会自动删除用户数据或收藏。高级区仍支持自定义 JSON 包，单包限 10 MB；导入成功不代表来源已通过内容质量审核。

此前设置没有来源模式字段时，更新后默认使用联网科普；已有剧情日期、地点及严格时间线设置仍用于离线检索。[v0.3.0 验收](docs/ACCEPTANCE-v0.3.0.md) · [资料来源政策](docs/KNOWLEDGE-SOURCE-POLICY.md) · [联网接口与边界](docs/ONLINE-SOURCES.md) · [ZIM 来源](docs/ZIM-SOURCES.md) · [历史 v0.2.0 验收](docs/ACCEPTANCE-v0.2.0.md)

## 开发与验证

~~~sh
npm install
npm run build
npm test
npm run preview
~~~

浏览器验收（需可用的 Playwright 与 Chromium）：

~~~sh
node scripts/online-browser-smoke.mjs
node scripts/zim-browser-smoke.mjs path/to/wikibooks_zh_all_nopic_2026-07.zim
node scripts/zim-timeout-smoke.mjs path/to/wikibooks_zh_all_nopic_2026-07.zim
~~~

默认预览为 http://127.0.0.1:4179；可设置 KNOWLEDGE_PHONE_PREVIEW、KNOWLEDGE_PHONE_PLAYWRIGHT、KNOWLEDGE_PHONE_CHROME。--host 针对已安装扩展的本地验卡 SillyTavern，使用专用测试卡；测试脚本阻断模型生成请求。具体版本的测试、浏览器与真实宿主证据须分开记录，历史验收不自动证明新版通过。

src/providers/online.ts 管理官方检索和读取，src/library/online-cache.ts 管理已读缓存；src/zim/engine.ts 管理 OpenZIM 工作线程，src/providers/zim.ts 管理离线检索，src/ui/archive-reader.ts 管理原文沙箱。正式安装使用仓库已编译的 dist/。旧采集脚本仅供格式回归，不再作为正式资料供给方案。
