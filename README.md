# 掌上知库 · Knowledge Phone

SillyTavern 浏览器扩展。连接成熟的离线知识库，精确查词、沿来源链接理解名词、直接阅读原文。不使用模型写百科，也不把摘要拼装成全文。

## 安装与开始使用

1. SillyTavern ≥ 1.18.0 → 扩展 → 安装扩展：`https://github.com/louisSSR/st-knowledge-phone`
2. 打开右下角「掌上知库」→「知库」，选择本地完整 `.zim` 文件。
3. 根据你的用途设置世界时间。2026 年的库快照默认不能用于 2008 年的严格剧情；日常科普可选择「现代模式」或明确关闭严格时间线。
4. 搜索名词，在结果中打开原文；点击原文内部链接继续查词，点击书签按聊天收藏。

无需 Python、Node、数据库服务、API Key 或模型费用。扩展随附约 2.32 MB 的离线引擎，**资料库单独下载**。第一次打开相关引擎后，搜索和阅读不请求外部网站。外部来源链接只有点击时才访问。

### 从哪里获得资料

- [Kiwix 官方库目录](https://library.kiwix.org/)：按语言、主题和体积选择成熟资料库。
- [中文维基教科书，2026-07，无图完整正文，94.40 MiB](https://download.kiwix.org/zim/wikibooks/wikibooks_zh_all_nopic_2026-07.zim)：本版实际验收样本，8,302 篇；包含「扑克」和「扑克/术语表」，不保证覆盖所有百科词条。
- [维基百科整库目录](https://download.kiwix.org/zim/wikipedia/)：`nopic` 无图、保留正文；`mini` 只含导言，不能代替全文库。中文 nopic 2026-07 约 14.75 GB，本版未下载或实测该整库。

下载完成后直接连接原文件，不重新采集、清洗、切片或复制到浏览器数据库。文件由浏览器按需读取；当前一次连接一个库。刷新页面后需重新选择同一文件，无需重新下载。连接记录、设置、查询历史、收藏在当前浏览器本地保存；资料文件本身仍在原来的位置。

## 搜索与阅读质量

- 复用 OpenZIM 原生标题索引与全文索引，标题精确匹配优先。短自然问句可提取名词，但不生成答案。
- 中文索引存在拆字误命中。本扩展对标题、原文片段或候选正文核对查词，过滤不含查词的无关命中。每次最多核对 30 个全文候选、呈现最多 100 条合并结果；界面明确提示这一边界，**不声称穷尽整库**。
- 原文中的标题、列表、表格、静态公式、来源署名与链接保留。术语解释使用来源自己的条目与链接；原文没有解释时，不自行编造。
- 主页从当前聊天明确标注的「话题/关键词/人物」生成可点击查询入口。不开额外模型、不上传聊天、不捏造推荐条目。
- HTML 在禁用脚本的沙箱中阅读，拒绝外部自动请求。离线资源有预算；依赖 JavaScript 的互动、视频与动态公式不保证可用。
- ZIM 原有分类不强制猜成游戏/人物/商品等类型；使用「全部」或「原文词条」。简繁体、同义词不做全量自动转换，可按来源词形查询。

快照时间目前来自文件名月份，并以月末保守过滤，**不是逐条历史版本核验**。没有日期的库在严格时间线中不可用。阅读页保留原文来源，资料许可由来源决定，不标成插件原创。

## 旧版资料

v0.1 的原创规则演示与 105 篇 Wikipedia 摘录已整体退出正式搜索、推荐与目录。它们是开发测试资产，不能作为完整科普资料交付；更新不会擅自删除用户已安装的数据或收藏。自定义 JSON 格式保留在知库的高级区，单包限 10 MB。

## 开发与验证

```sh
npm ci
npm run build
npm test
npm run preview
```

真实库浏览器验收：

```sh
node scripts/zim-browser-smoke.mjs path/to/wikibooks_zh_all_nopic_2026-07.zim
```

默认访问 `http://127.0.0.1:4179`；可设置 `KNOWLEDGE_PHONE_PREVIEW`、`KNOWLEDGE_PHONE_PLAYWRIGHT` 和 `KNOWLEDGE_PHONE_CHROME`。传 `--host` 可针对已安装扩展的本地验卡 SillyTavern，使用已有专用测试卡。测试脚本阻断模型生成请求。

旧采集脚本和样本测试仅用于旧格式回归，**通过测试不代表旧资料有科普价值**。不再运行逐篇采集作为正式资料供给方案。

运行引擎固定为 OpenZIM javascript-libzim v0.95，源码、二进制出处和校验值见 [第三方说明](vendor/libzim/NOTICE.md)。`src/zim/engine.ts` 管理工作线程，`src/providers/zim.ts` 管理检索质量和库切换，`src/ui/archive-reader.ts` 管理原文沙箱与资源释放。正式安装使用仓库已编译的 `dist/`。
